# Flood Tuber 头像包 – 简体中文

本包包含适用于 **Flood Tuber** OBS Studio 插件（Poste2Travail 增强版）的即用型头像文件夹。

## 使用方法
1. 安装 Flood Tuber。
2. 解压此 ZIP。
3. 将文件夹复制到：
   `C:\ProgramData\obs-studio\plugins\flood-tuber\data\avatars\`
4. 在 OBS 中添加 **Flood Tuber 头像** 源，从库中选择头像并点击 **加载并应用**。

## 严格文件命名
插件只识别精确文件名：
- `idle.png`（必需）
- `talk_a.png`、`talk_b.png`、`talk_c.png`
- `blink.png`、`action.png`
- 可选：`talk_a_blink.png` 等

## 创建自己的头像
可生成所需表情的免费工具：
- https://charat.me
- https://picrew.me

导出不同嘴型/眼睛状态并精确重命名。

每个文件夹包含示例 `settings.ini`。
