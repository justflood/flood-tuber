# Flood Tuber アバターパッケージ – 日本語

**Flood Tuber** OBS Studio プラグイン（Poste2Travail 強化版）用のすぐに使えるアバターフォルダです。

## 使い方
1. Flood Tuber をインストールします。
2. この ZIP を展開します。
3. フォルダを以下にコピーします：
   `C:\ProgramData\obs-studio\plugins\flood-tuber\data\avatars\`
4. OBS で **Flood Tuber アバター** ソースを追加し、ライブラリから選んで **読み込んで適用** をクリックします。

## 厳密なファイル名
プラグインは正確なファイル名のみを認識します：
- `idle.png`（必須）
- `talk_a.png`、`talk_b.png`、`talk_c.png`
- `blink.png`、`action.png`
- オプション：`talk_a_blink.png` など

## 自分のアバターを作る
必要な表情を持つキャラクターを生成できる無料ツール：
- https://charat.me
- https://picrew.me

口や目の状態をエクスポートし、上記の名前に正確にリネームしてください。

各フォルダにサンプル `settings.ini` が含まれています。
